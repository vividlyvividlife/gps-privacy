Политика конфиденциальности приложения «Скорость GPS»

Дата обновления: 19.11.2026

1. Оператор

Оператор обработки данных — разработчик приложения Vivid. Контакт для обращений: vividly.vividlife@gmail.com.

2. Какие данные обрабатываются

  • данные о местоположении: широта, долгота, точность, скорость, направление и время;
  • история поездок: координаты, время, скорость и пройденный путь;
  • пользовательские настройки приложения.

Приложение не запрашивает имя, телефон, адрес электронной почты, контакты и фотографии и не создаёт учётную запись.

3. Зачем нужны данные

Данные используются только для работы функций приложения: отображения скорости по GNSS, записи трека и расчёта пути, истории поездок, карты, секундомера, фоновой записи и предупреждения о превышении заданной скорости.

Правовое основание обработки — согласие пользователя, которое он даёт перед запросом доступа к геолокации.

4. Где хранятся данные

История поездок и настройки хранятся только на устройстве пользователя в защищённом хранилище приложения. Приложение не отправляет историю поездок на сервер разработчика и не использует облачную синхронизацию. Резервное копирование данных приложения отключено.

Срок хранения — до удаления истории пользователем, очистки данных приложения или удаления приложения.

5. Передача данных третьим лицам

История поездок не продаётся и не передаётся третьим лицам.

При открытии экрана карты приложение загружает картографические тайлы OpenStreetMap с сервера tile.openstreetmap.org. Этот запрос технически передаёт IP-адрес, user-agent и координаты запрашиваемого участка карты. Это необходимо для отображения карты; история поездок при этом не передаётся. Политика OpenStreetMap: openstreetmap.org/copyright.

В текущей версии реклама не отображается и аналитические SDK не используются. В интерфейсе есть зарезервированная область под рекламный блок; при подключении рекламных сервисов эта политика будет обновлена.

6. Удаление данных и отзыв согласия

Пользователь может удалить историю поездок в приложении: «Настройки» → «Очистить историю». Также можно удалить все данные приложения средствами Android или удалить приложение. Отключение доступа к геолокации прекращает получение новых данных; ранее записанная история остаётся на устройстве до её удаления.

7. Безопасность

Доступ к данным имеет только приложение в пределах песочницы Android. Приложение не содержит рекламных и аналитических трекеров, не запрашивает контакты, SMS, файлы и другие данные, не связанные с его функциями.

8. Изменения политики

Актуальная версия политики доступна в приложении в разделе «Настройки» → «Политика конфиденциальности». При существенных изменениях будет обновлена дата редакции.
